Recover leftovers without deleting unknown files draft-copy

Audience: both
When: Uninstall or reinstall reports stale foreign-install state or partial failure
Need: Setup offers Unlink and set up fresh when a checkout links to a project the chosen install lacks or the account cannot access. Project uninstall still removes the layer when the owning install is gone and warns that the commit belongs on the default branch. Machine uninstall skips Docker without a self-host install, strips Yoke's Cursor user hooks, and reverts only the harness settings it recorded writing while they still hold Yoke's value; changed settings are reported and kept, and a failed revert keeps the machine home for a retry.
